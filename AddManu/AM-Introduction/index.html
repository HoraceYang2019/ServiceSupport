    全域重要限制

    • 本專案使用 2 µm 預設 Cartesian voxel，但物理場並非「每個 voxel 一律固體」。
    • pressure_gpu.py 目前是 GPU Jacobi 近似解，不能宣稱已證明收斂或已通過 benchmark。
    • vof_gpu.py 為一階迎風、非 PLIC；clip 不保證嚴格全域體積守恆。
    • simulation_engine.py 尚未實現完整守恆焓平流，移動 VOF 與熱量需額外驗證。
    • v2.9 自適應 Jacobi 早停有改變結果的可能；不得把效能改善解讀為物理精度提升。
    • 冷卻完成係指 max fL <= COOL_FL_TOL，不是一定冷卻到室溫。
    • 程式安全停止與緊急 NPZ 不代表該物理場正確。

    AI 建議的修改順序

    1. 檢查 process_parameters.py 以及 material_parameters.py 的物性、數值條件。
    2. 查閱目標模組的 Markdown Input / Output 與源碼。
    3. 搜尋上游／下游函數呼叫與輸出欄位。
    4. 先通過語法測試，再在 NVIDIA GPU 進行小網格數值測試、守恆測試、效能 profiling。
    5. 同步更新所有受影響的 Markdown。
