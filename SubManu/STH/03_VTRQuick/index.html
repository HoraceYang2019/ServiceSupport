    3 虛擬刀房- 快速操作流程

    基於智慧刀把的虛擬刀房快速操作流程，包含計畫設定與準備、智慧刀把連線檢查、智慧刀把資料設定、資料蒐集、資料檢視與分析、異常事件和錯誤處理等快速操作流程，以下說明。

    3.1 計畫設定

    • 前往計畫設定頁面(如圖 7)，按下NEW PLAN(新建計畫)建立新的生產或實驗計畫，設定機台ID、材料、加工模式和刀把的MAC與Port號，並綁定對應的刀具ID。

    • 如果需要更新現有計畫，可以使用UPDATE PLAN(更新計畫)按鈕。

    • 使用BIND(綁定)功能來設定每個智慧刀把的MAC與對應的刀具編號。

    圖 7、計畫設定頁面

    3.2 連線檢查

    • 在連線檢查頁面上(如圖 8)，Networking(TCP/IP設定)區域中，將ST_route放置在靠近CNC機台的位置，確保穩定的Wi-Fi連接，並設定正確的IP位址。

    • 在連線檢查頁面中，按下LOAD STHSCAN以載入STH掃描程序，並使用RE-SCAN確保所有智慧刀把都成功掃描並連接。

    • 訊號強度可以在即時監控頁面上查看。

    • 當 (RSSI > -50 dB)範圍時，表示智慧刀把與 Router 的訊號強度足夠。

    • 當 (RSSI ≤ -50 dB )範圍時，表示訊號強度不足，可能導致連線中斷或資料不完整，需要重新掃描智慧刀把。

    圖 8、連線檢查頁面

    3.3 資料設定

    • 前往儲存設定頁面(如圖 9)，在Data Parsing(TXT->CSV)區域中，確認是否需要儲存原始數據以及解析後的數據(例如CSV文件)。這些設定可以確保後續的數據能夠正確保存，便於進行進一步的分析。

    • 確保所有設定已應用(APPLY UPDATES)，以便實驗過程中數據能順利保存。

    圖 9、資料設定頁面

    3.4 資料蒐集

    • 前往即時監控頁面(如圖 10)，按下LOAD ALL(載入所有)啟動STH連線和數據處理程序，此時智慧刀把顯示燈號為藍色，代表正常連線中．

    • 確認連接狀態良好，然後按下START RECORD(開始記錄)紀錄來自STH的感測數據(TXT文件)，可以設置Stop In Time(s)指定自動停止記錄的時間。

    • Recording Time會顯示已錄製的時間，確保記錄時間涵蓋到想要觀察的整個加工過程。

    圖 10、資料蒐集頁面

    3.5 資料檢視

    • 選擇有效的時間段進行分析:

    • 蒐集到的數據需要有效分析才能得出可靠結論。在歷程檢視頁面中(如圖 11)，選擇要回顧的資料檔案，並設定合理的時間間隔(Time Interval)來控制數據的顯示解析度。

    • 觀察上、下管制界線，需選取Folder和File後按下「ADD UCL LCL」，將會為選取的CSV檔增加上、下管制界線，名稱為原檔名+_processed。

    • 在Summary(摘要)區域中，查看Start Time和End Time，選擇在穩定加工階段內的數據進行分析。確認各通道的最大值(如CH1 Max、CH2 Max等)是否在合理範圍內，並檢查Quality指標是否為合格狀態(顯示為1)。

    • 模擬結果的分析:

    • 在模擬分析頁面中，選擇要分析的模擬CSV檔案，使用各種折線圖檢視不同軸向的力矩和位置變化，圖表能幫助了解工具在加工過程中的受力和位移情況。

    圖 11、資料檢視與分析頁面

    3.6 異常處理

    • 異常事件儲存設定:

    • 前往儲存設定頁面，在File Location區域中，設定儲存位置確保發生異常事件檔案正確儲存。

    • 虛擬刀房異常事件的日誌文件，產生的日誌文件將會記錄STH以及Node Red系統運行過程中的異常事件和錯誤，以便於後續的排查和問題診斷。
