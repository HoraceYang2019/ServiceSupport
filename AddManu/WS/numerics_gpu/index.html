    numerics_gpu.py｜GPU 基礎有限差分

    對應版本：LPBF 26-Step GPU v2.9。以實際 Python 原始碼為準；本文件不代表已通過 GPU 實測或數值驗證。

    1. 程式說明 / Responsibility

    提供 grad、div、lap 等三維差分運算。

    計算流程： 回傳相同 shape 的 CuPy 數值場。

    2. Input（輸入）

    以下為原始碼函數簽章，名稱與參數順序直接對照 Python：

    grad(a, dx, dy, dz)

    Input 含義／單位
    a 請依原始碼確認具體物件/形狀與單位
    dx voxel 尺寸 m
    dy voxel 尺寸 m
    dz voxel 尺寸 m

    Output（回傳）：(gx,gy,gz): 三維偏導數

    原始回傳表達式： - return gx,gy,gz

    div(x, y, z, dx, dy, dz)

    Input 含義／單位
    x 請依原始碼確認具體物件/形狀與單位
    y 請依原始碼確認具體物件/形狀與單位
    z 請依原始碼確認具體物件/形狀與單位
    dx voxel 尺寸 m
    dy voxel 尺寸 m
    dz voxel 尺寸 m

    Output（回傳）：散度場

    原始回傳表達式： - return a+b+d

    lap(a, dx, dy, dz)

    Input 含義／單位
    a 請依原始碼確認具體物件/形狀與單位
    dx voxel 尺寸 m
    dy voxel 尺寸 m
    dz voxel 尺寸 m

    Output（回傳）：Laplacian 場

    原始回傳表達式： - return (xp+xm-2*a)/dx**2+(yp+ym-2*a)/dy**2+(zp+zm-2*a)/dz**2

    3. Output（輸出）與副作用

    • 直接輸出： 上述函數回傳資料。
    • 檔案寫入： 此模組本身不負責一般 NPZ 寫入。

    4. 程式依賴與 GPU/CPU 邊界

    • 專案內相依模組：無直接同專案 import。
    • 主要 GPU 場使用 CuPy；float(...)、.get()、cp.asnumpy() 可能產生同步。不要在每個 voxel 的 Python 迴圈中逐一搬運。
    • material_parameters.py 與 process_parameters.py 在 CPU 設定材料與製程常數；GPU 計算模組讀取這些常數。

    5. 物理公式／數值實作對照

    此檔案的公式、係數及離散方式請以相同版本 .py 的實作為準，勿從模組名稱推斷未實作功能。

    6. AI 修改約束 / AI Editing Rules

    1. 此模組的中心差分與 pressure_gpu 的面速度離散不應混為一談。
    2. 修改函數名稱、輸入或回傳時，需同步搜尋所有呼叫者並更新此 MD。
    3. 維持 F（金屬 VOF）、fL（液相率）、alphaL=F*fL 三者的不同含義。
    4. GPU 欄位優先使用 CuPy float32；不可為了加速而省略必要的 CFL、散度與守恆檢查。
    5. 若程式本身未實作特定物理功能，不得在 AI 說明中宣稱已實作。

    7. 程式位置及檢查

    • 原始碼：../numerics_gpu.py
