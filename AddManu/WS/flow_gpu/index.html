    flow_gpu.py｜三方向速度預測與壓力修正

    對應版本：LPBF 26-Step GPU v2.9。以實際 Python 原始碼為準；本文件不代表已通過 GPU 實測或數值驗證。

    1. 程式說明 / Responsibility

    計算動量平流、黏性、界面力、糊狀區阻尼及浮力，再呼叫壓力投影。

    計算流程： 返回 u,v,w；pressure_gpu.project 返回面速度供 VOF 使用。

    2. Input（輸入）

    以下為原始碼函數簽章，名稱與參數順序直接對照 Python：

    update_velocity(u, v, w, T, fL, F, forces, dt)

    Input 含義／單位
    u X 正向面速度 m/s，GPU 3D float32
    v Y 正向面速度 m/s，GPU 3D float32
    w Z 正向面速度 m/s，GPU 3D float32
    T 溫度 K，GPU 3D float32
    fL 液相率 [0,1]，GPU 3D float32
    F 金屬體積分率 VOF [0,1]，GPU 3D float32
    forces 三個 GPU float32 力場，N/m³
    dt 物理時間步長 s；CPU float / GPU float32 scalar

    Output（回傳）：(u,v,w): 投影後三方向面速度，m/s

    原始回傳表達式： - return project(*next_vel,fluid,dt,F) - return u,v,w

    3. Output（輸出）與副作用

    • 直接輸出： 上述函數回傳資料。
    • 檔案寫入： 此模組本身不負責一般 NPZ 寫入。

    4. 程式依賴與 GPU/CPU 邊界

    • 專案內相依模組：material_parameters.py, numerics_gpu.py, pressure_gpu.py。
    • 主要 GPU 場使用 CuPy；float(...)、.get()、cp.asnumpy() 可能產生同步。不要在每個 voxel 的 Python 迴圈中逐一搬運。
    • material_parameters.py 與 process_parameters.py 在 CPU 設定材料與製程常數；GPU 計算模組讀取這些常數。

    5. 物理公式／數值實作對照

    u* = u + dt[-(u·∇)u + ν∇²u + f/ρ - damping*u + buoyancy]，再投影。

    6. AI 修改約束 / AI Editing Rules

    1. 輸出面速度的意義要與 vof_gpu 一致，避免重複插值。
    2. 修改函數名稱、輸入或回傳時，需同步搜尋所有呼叫者並更新此 MD。
    3. 維持 F（金屬 VOF）、fL（液相率）、alphaL=F*fL 三者的不同含義。
    4. GPU 欄位優先使用 CuPy float32；不可為了加速而省略必要的 CFL、散度與守恆檢查。
    5. 若程式本身未實作特定物理功能，不得在 AI 說明中宣稱已實作。

    7. 程式位置及檢查

    • 原始碼：../flow_gpu.py
    • 此文件是 v2.9 程式的閱讀指南。若程式更新版本，應重新檢查 Input/Output。
