    感測資料Issues

    Issue No Time Task
    1 2026-10-16 確認要納入 Spray Line 計畫的感測資料

    1. 感測資料

    類別 中文名稱 建議欄位名稱 單位 / 型態 說明
    噴塗製程 塗料流量 paint_flow_ml_min mL/min 記錄噴塗時塗料供應流量，可用於判斷供料穩定性與噴塗品質。
    濾網 濾網壓差 filter_diff_pressure_bar bar 用於觀察濾網前後壓差變化，可作為濾網堵塞或劣化判斷依據。
    機械手臂 伺服馬達負載 servo_torque_load_pct % 記錄伺服馬達 / 關節負載，可用於設備狀態與預測性維護分析。
    噴塗製程 空氣壓力 air_pressure_bar bar 記錄噴塗霧化使用的空氣壓力，可用於判斷噴塗製程穩定性。
    噴塗品質 噴幅寬度 spray_width_mm mm 資料來源需再確認是感測器直接量測，或由 CCD / 影像系統量測。
    機械手臂 軌跡誤差 path_error_mm mm 記錄實際路徑與目標路徑之間的偏差，可反映定位或路徑追蹤異常。
    環境 環境溫度 temperature_c °C 記錄噴塗環境溫度，用於分析環境條件對製程的影響。
    環境 環境濕度 humidity_rh %RH 記錄環境相對濕度，用於分析環境條件與噴塗品質之間的關係。
    噴嘴 / 塗料供應 噴嘴壓力 nozzle_pressure_bar bar 用於記錄噴嘴端或塗料端實際壓力；需再確認現場是否有可讀取的壓力訊號。
    機械手臂 機械手臂位置 X tcp_x_mm mm 記錄工具中心點（TCP）X 軸位置。
    機械手臂 機械手臂位置 Y tcp_y_mm mm 記錄工具中心點（TCP）Y 軸位置。
    機械手臂 機械手臂位置 Z tcp_z_mm mm 記錄工具中心點（TCP）Z 軸位置。
    機械手臂 機械手臂速度 speed_mm_s mm/s 記錄機械手臂移動速度，可配合路徑誤差與噴塗條件分析。

    2. 目前暫定分類

    噴塗製程
├─ 塗料流量
├─ 空氣壓力
├─ 噴幅寬度
└─ 噴嘴壓力

設備 / 預測性維護
├─ 濾網壓差
└─ 伺服馬達負載

機械手臂
├─ 軌跡誤差
├─ TCP X
├─ TCP Y
├─ TCP Z
└─ 移動速度

環境
├─ 環境溫度
└─ 環境濕度

    3. 確認的項目

    目前先暫定以上資料項目，需再確認：

    噴幅寬度的來源 - 是實體感測器直接量測； - 還是 CCD / 相機影像計算； - 或由其他製程系統提供。

    機械手臂位置資料 - 確認 X / Y / Z 是不是 TCP 位置； - 確認座標系統； - 確認更新頻率。

    更新頻率 - 製程與設備資料是否統一每 1 分鐘保存； - 環境資料是否每 3 分鐘保存；

    4. 結論

    目前需要保留的核心資料為：

    1. 塗料流量
2. 濾網壓差
3. 伺服馬達負載
4. 空氣壓力
5. 噴幅寬度
6. 軌跡誤差
7. 環境溫度
8. 環境濕度
9. 噴嘴壓力
10. 機械手臂位置 X / Y / Z
11. 機械手臂速度
